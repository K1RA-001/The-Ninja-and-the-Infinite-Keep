# The Ninja and the Infinite Keep

An endless vertical platformer built in Godot 4.7.

Climb a royal fantasy keep one balcony at a time. Keep moving as the camera rises, read the randomized castle traps, and stay above the fall line. The keep starts out with jokes at your expense, then quietly becomes more encouraging the longer you persist.

## Features

- Endless castle climb with varied balconies, ridges, and trap layouts
- Camera that rises behind the player; falling below it ends the run
- Randomized hazards with varied placement, width, height, and appearance
- Pixel-art royal ninja character
- Funny death messages that gradually turn supportive
- Hidden adaptive help for repeated attempts
- Original synthesized game sound effects

## Controls

| Key | Action |
| --- | --- |
| `A` / `D` or `Left` / `Right` | Move |
| `W`, `Up`, or `Space` | Jump |
| `R` | Restart |
| `Esc` | Return to the main menu |

## Running the game

1. Install Godot **4.7**.
2. Open `project.godot` in Godot.
3. Press `F6` or `F5` to play.

## Project structure

- `Scenes/` — menu, player, platform, spike, and main game scenes
- `Scripts/` — movement, camera, endless-world generation, UI, sound, and castle rendering
- `Assets/` — original project art
