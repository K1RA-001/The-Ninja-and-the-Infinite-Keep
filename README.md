# Ninja Keep — Again!

A pixel-styled, endless ninja climb through a lantern-lit castle, made with Godot 4.7. The title screen includes controls, and the game generates its own original synthesized sound effects.

## Run it

Open `project.godot` in Godot 4.7 and press **F6** or **F5**.

## Controls

- **A / D** or **Left / Right arrows** — move
- **Space**, **W**, or **Up arrow** — jump
- **R** — restart the run

Climb the stone ledges, avoid the castle traps, and reach the summit flag before the camera scrolls past you. Your timer and wipeouts are shown in the top bar. Death messages start teasing you and gradually turn into a pep talk. Finish faster with fewer wipeouts for a higher score.
